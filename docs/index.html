Privacy by Design, Not as an Afterthought

We believe your personal credentials and identity data should never leave your hardware.

No backend servers, no analytics, no third-party tracking. Our automated CI checks verify zero network APIs in production source.

Frequently Asked Questions

Everything you need to know about Stashfill and how it safeguards your data.

Does Stashfill require an account or login?
No. Stashfill is completely account-free and no-login. You install the extension, enter your information locally, and start using it immediately.
Are my payment card numbers safe?
Yes. Payment cards can only be stored inside an encrypted vault locked with your master passphrase. Encryption uses AES-GCM 256-bit with PBKDF2 (600,000 iterations). Cards are never passively filled and require explicit user confirmation.
How does Stashfill handle React or Vue controlled inputs?
Many modern forms reject standard programmatic changes because of framework internal trackers. Stashfill directly overrides the prototype value setter, resets the framework's internal value tracker, and dispatches bubbled input and change events so forms recognize the filled values without errors.
Is cloud synchronization available?
Not in Version 1.0. Stashfill is intentionally strictly offline-first. End-to-end encrypted synchronization (via WebDAV or user-owned cloud) is planned for future updates behind an abstract storage adapter.
